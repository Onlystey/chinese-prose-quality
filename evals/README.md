# 行为评测

本目录样例为原创构造。评测对象是实际文字处理结果，不是技能文件是否包含某句口号。参考改写不是唯一答案；保意、诊断正确和不过改更重要。

评估时仅把题目、必要语境与技能提供给独立执行者，不先提供期望诊断或答案。保存原输入、实际回答、日期、模型可核验信息与评分理由；不要用模型自行声称“我已逐句检查”作为通过证据。

## 四项共同标准

1. 修正明确错误，给出的理由与实际句子相符。
2. 保留事实、范围、否定、程度、时间、态度和术语；不补造依据。
3. 正确例保持可用，不因表面风险信号误改。
4. 必须有语境才能判断的题，不自作主张选定原意。

文件格式可能按各组组织；先读每组字段定义。所有样例都应能以“必须纠错、应保留、需语境”之一或多项表达验收目标。

## 文体与完整修订

另外用连续段落测试：论文标题与论证任务、教材行动主体、小说物件与对白、全文重复错误回归。给足原意约束，检查执行者是否只改首个例子。对文件任务，语言审校与格式保真分开验收。

## 如何解释通过

脚本测试、规则覆盖、单句评测、连续段落评测和新进程触发验证是不同层次。报告具体层次与实际样本数，不把未执行的题目计为通过，不把测试通过等同于未来无错，也不以检测器分数替代语言判断。
